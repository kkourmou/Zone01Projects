# ASCII-ART-FS

Renders text as ASCII art and prints the result at CLI.

## Usage

```
go run . "<text>" [banner] | cat -e
```

- `banner` — font to use: `standard` (default), 'stef', `shadow`, `thinkertoy`

## Requirements

- Go 1.24+
- Only printable ASCII characters and `\n` are supported

## Project Structure

```
.
├── main.go
├── ascii-style/        # Banner font files
│   ├── standard.txt
│   ├── shadow.txt
│   └── thinkertoy.txt
└── internal/
    ├── args/           # CLI argument parsing
    ├── parser/         # Banner file parsing
    └── renderer/       # ASCII-art rendering
```
